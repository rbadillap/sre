# Review

These pages are the rules a change has to meet before it's merged. They work the same way for a person reviewing a pull request and for an agent asked to review one.

Each rule has three parts:

- **Rule**: what has to be true.
- **Why**: what goes wrong without it.
- **Check**: how to tell, by reading the change.

A change passes when every rule that applies to it passes. If a rule doesn't fit a case, change the rule in its own pull request first. Don't skip it quietly.
