# Changelog

What changed in each version, and why. Changes that come from the learning loop say which kind of incident taught them, in general terms.

The package follows [semantic versioning](https://semver.org): a new skill or template is a minor version; a change that breaks how an existing skill is used, or where it writes, is a major version.

## Unreleased

- The method, the lifecycle, the layers and the landscape, in `docs/`.
- Review rules for skills, disciplines, templates, evals and documents, in `docs/review/`.
- The shared glossary.
- First orchestrators: `find-blind-spots`, `review-release`, `respond-to-alert` and `write-postmortem`, each with its template.
- `make validate`, which checks `plugin.json` against the Agent Plugins schema and every skill against the Agent Skills spec.
- First disciplines: `reframe-first`, `scope-and-signal`, `reversible-first`, `state-is-special`, `evidence-before-claims`, `verified-impact` and `paved-road`.
